# ShopDiscount — GP247 / S-Cart 向け割引コード（クーポン）プラグイン

## はじめに
ShopDiscount は、GP247 / S-Cart 3.0 で動作する EC サイト向けに **割引コード（クーポン）** を作成・管理できる
プラグインです。管理者が割引コードを作成し、お客様は **決済ステップ** でコードを入力すると注文金額の
割引を受けられます。本ドキュメントはショップのオーナーと管理者（プログラミングの知識は不要）向けです。
読み終えると、インストール方法、割引コードの作成方法、そしてお客様がコードをどのように使うかが分かります。

## 主な機能
- **2 種類の割引方式：**
  - **Point** — **固定金額** を割引します（例：50,000 VND 割引）。
  - **Percent (%)** — 注文金額の **パーセンテージ** で割引します（例：10% 割引）。
- コードごとの **利用回数の上限**（例：100 回までのみ利用可能）。
- **ログイン必須**（任意）：ログインしたお客様だけがコードを利用でき、各お客様は 1 回のみ利用できます。
- コードの **有効期限**。
- 各コードをいつでも **有効化／無効化**。
- **マルチストア対応：** コードを適用するストアを選択できます。
- **決済ページですぐにコードを適用：** お客様がコードを入力 → 割引行と合計金額がすぐに更新されます
  （ページの再読み込みは不要）。

## 動作要件
| コンポーネント | 要件 |
| --- | --- |
| GP247 Core | **3.0** |
| 必須パッケージ | **gp247/shop**（EC サイト用） |
| プラグインのバージョン | 3.0 |

> ウェブサイトに `gp247/shop` がインストールされていない場合、プラグインは正しく動作しません（販売機能のためのプラグインです）。

## インストール
インストール方法は 4 つあります（GP247 のすべての拡張機能と同様で、コマンドライン CLI でのインストールも含みます）。プラグインのフォルダがすでに手元にある場合の最も早い方法：

1. プラグインのフォルダをサーバー上の正しい場所にコピーします：

   ```
   app/GP247/Plugins/ShopDiscount
   ```

2. 拡張機能の管理権限を持つアカウントで **admin** にログインします。
3. **Plugin** メニューを開き、一覧から **ShopDiscount** を探して **インストール (Install)** をクリックします。
   成功すると、インストール成功のメッセージが表示され、admin に **Discount**
   （Coupon/Discount）という新しいメニュー項目が表示されます。
4. （admin の表示が古いままの場合）ウェブサイトのルートフォルダで **Terminal** を開き、次の行をそのまま入力して Enter を押し、
   キャッシュをクリアします：

   ```
   php artisan optimize:clear
   ```

> **Online（拡張機能ライブラリ）** または **.zip ファイルのインポート** でインストールしたい場合は、共通のインストールガイドをご覧ください：
> [GP247 のプラグインとテンプレートのインストールガイド](https://github.com/gp247net/gp247-docs/blob/main/extension/install-extension.md)。

### コマンドラインでのインストール（CLI、gp247 3.x）

gp247 3.x 以降では、管理画面を開かずに、GP247 ライブラリから **ShopDiscount** をダウンロードしてコマンドラインですぐにインストールできます。ウェブサイトのルートフォルダでターミナルを開き、次を実行してください：

```bash
# 1) ウェブサイトごとに 1 回だけ：GP247 ライブラリに接続するための API License（無料）を登録
php artisan gp247:ext-register-license

# 2) ライブラリからプラグインをダウンロードしてインストール
php artisan gp247:ext-install --type=plugin --key=ShopDiscount
```

- 手順 1 の前に、`.env` の `APP_URL` がウェブサイトの **実際のドメイン** になっていることを確認してください（`http://localhost` のままにしないでください）。ライセンスはこのドメインに紐付けられます。
- インストールが完了すると、プラグインは **有効化済み** になり、キャッシュも自動で更新されるため、管理画面で追加の操作は必要ありません。
- コマンドは `gp247.json` に宣言された条件（core のバージョン、composer パッケージ、依存プラグイン）を自動でチェックします。不足があればコマンドは停止し、何が足りないかを明示します。
- このプラグインには `gp247/shop` パッケージのインストールが必要です。不足している場合、コマンドは停止して通知します。
- `app/GP247/Plugins/ShopDiscount` フォルダがすでにサーバー上にある場合（手動でコピーした、またはインストールパッケージに同梱されていた場合）、コマンドは再ダウンロードせずに **その場でインストール** します。
- プラグインがすでにインストール済みの場合、コマンドは拒否します。新しいバージョンに更新するには `php artisan gp247:ext-update --type=plugin --key=ShopDiscount` を実行してください。
- コマンドの末尾に `--json` を付けると、機械可読な形式で結果を受け取れます（スクリプト／CI 用）。
- このコマンドは上記の手順 1〜3 の代わりになります。手順 4 はそのまま必要です：admin の表示が古いままの場合（**Discount** メニューがまだ表示されない場合）は、`php artisan optimize:clear` を実行してください。
- 詳細：[プラグインとテンプレートのインストールガイド](https://github.com/gp247net/gp247-docs/blob/main/extension/install-extension.md) · [コマンドリファレンス](https://github.com/gp247net/gp247-docs/blob/main/system/command-line-reference.md)。

## 使い方 (1)：管理者が割引コードを作成する
1. admin で **Discount**（Coupon/Discount）メニューを開きます。
2. **新規追加 (Add new)** ボタンをクリックします。
3. 各項目を入力します：
   - **Code** — お客様が入力するコード（例：`SALE10`）。英字、数字、および `. - _` の記号のみ使用できます。
   - **Reward** — 割引額：*Point* を選んだ場合は **金額**、*Percent* を選んだ場合は **パーセント値** です。
   - **Type** — **Point**（金額で割引）または **Percent (%)**（% で割引）を選択します。
   - **Description** — コードのメモ（任意）。
   - **Limit** — コードを利用できる最大回数。
   - **Login require** — お客様にログインを必須とする場合はチェックします。
   - **Expires** — 有効期限（カレンダーから選択）。
   - **Status** — チェックするとコードが **有効** になります（チェックを外すと無効）。
   - **（マルチストア運用時のみ）** コードを適用する **ストア** を選択します。
4. **送信 (Submit)** をクリックして保存します。新しいコードが右側の一覧に表示されます。**Used** 列には、
   許可された合計回数に対してコードが何回使われたかが表示されます（例：`3/100`）。

## 使い方 (2)：お客様が決済時にコードを適用する
1. お客様が商品をカートに追加し、**決済 (Checkout)** に進みます。
2. **注文確認ステップ** で、お客様は **coupon** 欄にコードを入力し、**適用 (Apply)** をクリックします。
3. コードが有効であれば、**割引** 行が表示され、**合計金額がすぐに更新** されます。コードを取り消すには **削除 (Remove)** をクリックします。

コードが受け付けられるのは、次の条件をすべて満たす場合のみです：有効であること（有効化されており、期限切れでない）、**利用回数が残っている** こと、
適用対象の **ストア** が正しいこと、そして（コードが要求する場合）お客様が **ログイン済み** で、このコードをまだ使っていないこと。

## プラグインの有効化／無効化／削除
- admin → **Plugin** → **ShopDiscount** を開きます。
- **Enable / Disable** で一時的に有効化または無効化します（作成済みのコードのデータは失われません）。
- **Uninstall** で完全に削除します — この操作はプラグインの **割引コードのデータを削除** するため、実行前によく検討してください。

## Q&A（よくある質問）
**質問 1：お客様は割引コードをどこで入力しますか？**
決済（checkout）ページの **確認ステップ** に、クーポンコードの入力欄があります。コードを入力して「適用」をクリックしてください。

**質問 2：「Point」と「Percent」の違いは何ですか？**
*Point* は **固定金額** を割引します（例：50,000 VND）。*Percent* は注文金額の **パーセンテージ** で割引します
（例：10%）。**Reward** 欄には、選択した方式に対応する数値を入力します。

**質問 3：インストールしたのに admin に「Discount」メニューが表示されませんか？**
`php artisan optimize:clear` を実行してキャッシュをクリアし、admin ページを再読み込みしてください。また、Plugin メニューでプラグインが
**インストール済み + 有効 (Enable)** の状態になっているかも確認してください。

**質問 4：お客様がコードを適用したのに割引されませんか？**
コードが **有効 (Status)** であること、**期限切れでない** こと、**利用回数が残っている** こと（Used が Limit に達していない）、そして
**ストア** が正しいことを確認してください。コードで「Login require」が有効になっている場合、お客様は **ログイン** しないと利用できません。

**質問 5：1 つのコードは何回使えますか？**
**Limit** 欄に入力した回数までです。利用回数（Used）が Limit に達すると、コードは利用回数切れと表示され、それ以上使えなくなります。

**質問 6：プラグインを削除（Uninstall）すると、作成したコードは失われますか？**
はい。Uninstall を行うと割引コードのデータが削除されます。一時的に停止したいだけであれば、Uninstall ではなく **Disable** を使ってください。

**質問 7：複数のストアを運営している場合、コードはどのように適用されますか？**
ウェブサイトでマルチストアモードが有効な場合、コードを作成するときに適用する **ストア** を選択します。コードは選択したストアでのみ有効です。

**質問 8：プラグインに gp247/shop は必要ですか？**
はい。ShopDiscount は販売機能のためのプラグインなので、ウェブサイトに `gp247/shop` がインストールされていることが **必須** です。

**質問 9：「Login require」とはどういう意味ですか？**
**ログイン済み** のお客様だけがそのコードを利用でき、各アカウントはそのコードを **1 回だけ** 利用できるという意味です。

**質問 10：バージョン 3.0 へのアップグレード方法は？**
このバージョン 3.0 は **GP247 Core 3.0** 向けに作られています。プラグイン 2.x をお使いの場合は、その場で更新できます：admin →
**Plugin → From library** を開き、**Check update** をクリックしてから **Update 3.0** をクリックします（プラグインは 2.0 以降からの
直接更新に対応しています — `requireUpdateFrom` を参照）。コードのデータ構造は変わらないため、既存の割引コードは
そのまま保持されます。古い 1.x をお使いの場合は、Core 3.0 の環境にバージョン 3.0 を新規インストールしてください（1.x → 3.0 への
直接アップグレードには対応していません）。
